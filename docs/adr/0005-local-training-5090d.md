# 重训策略：本地 2× RTX 5090D，规格书起步、单摆辨识收尾

训练不走云租（AutoDL 4090 约 ¥2/时）也不降级为开环示教：用户本地有 2× RTX 5090D（Blackwell sm_120，32GB GDDR7），算力充足且零边际成本，适合重训的反复迭代。

质量标准分两阶段：v1 用 HD-1910 规格书参数搭 BAM 占位模型 + 域随机化放宽，以「能走」为验收（最快路径）；v2 用备用舵机做单摆台架辨识替换精确参数后重训，步态质量逼近原版。辨识参数今后每只鸭复用。

## Consequences

- 训练环境需 CUDA ≥12.8 的 PyTorch（Blackwell 架构要求）
- 本机另有 GTX 1050 Ti（4GB），不用于训练
- 收尾需要从补购批次留出 ≥1 只备用舵机做台架
