# 无臂形态：手臂 6 舵机不采购，手臂打印件封存

官方 Pollen Microduck 本身就是无臂设计；FanGe README 的 14 舵机 BOM 对应无臂版。用户已打印的是带臂版（19 舵机几何），装配时手臂件全部不用。砍臂省 6 舵机（≈¥738），且单协议（全 HD-1910）比原「腿 HD-1910 + 头 SCS0009」混搭简单得多。打印件封存不改造，保留日后补臂升级路径（届时再加 6 舵机 + 重训带臂策略）。

## Consequences

- 胸口两侧肩部开口留空（可后补打印盖板）
- 重训 MJCF 必须删除 6 个手臂 body/actuator（整段删除而非质量归零，使质量分布与实机一致）
- obs/action 维度相对原 walk.onnx（obs [1,51] / actions [1,14]）会变化，重训配置需自洽
